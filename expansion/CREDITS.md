Xsynth 2000 is a new digital synthesizer developed from Steve J. Brookes'
Xsynth 1.0.2 (1999). It retains the original project as its historical and code
foundation while substantially developing the synthesis architecture, modulation,
oscillator interaction, filtering, voice system, workflow, Windows VST3
implementation, and graphical interface.

Original notices and license are retained in AUTHOR and COPYING.
Synthesizer code is GPL-2.0-or-later.

Steinberg VST3 SDK: MIT license; see VST3-SDK-LICENSE.txt in the distribution
and external/vst3sdk/LICENSE.txt in the development checkout.

The metallic XSYNTH 2000 title is original fixed bitmap wordmark artwork
created for this project from independently constructed geometric primitives.
Artwork and generation code are provided under GPL-2.0-or-later. No third-party
font is bundled. See expansion/assets/FONT-SOURCE.md in the corresponding source.

Historical preset sources and notices are retained in the plugin's
Contents/Resources/Factory directory. See BANKS.md and manifest.json there for
Steve J. Brookes / Sean Bolton attribution and source provenance. The DSSI
importer is independently implemented from historical format/behavior research.
