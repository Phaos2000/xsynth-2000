Pre-pitch-extension importer archive (2026-10-17)

This is the preserved 54-WAV DSSI-derived baseline and corpus mapping from the
1..4 oscillator range. It includes the limited shared Master Tune workaround.
It is historical Xsynth 2000 importer output, not genuine Xsynth-DSSI audio.

The original README and SHA256SUMS are retained unchanged. Their bank/format
paths refer to the parent tests/dssi directory; reference/README paths refer
here. The same old reference/ files remain untouched in the parent directory.

Current direct-pitch output is recorded separately in ../reference-direct-pitch.
See ../../../PITCH_RANGE.md for migration, differences and verification results.
